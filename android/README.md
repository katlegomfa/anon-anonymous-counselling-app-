# Anon Android wrapper

Open this directory in Android Studio. The Kotlin WebView wrapper is a source project, not a compiled APK. Configure the approved HTTPS website URL in MainActivity.kt before release, then build and sign an APK/AAB with Android Studio.

Do not enable microphone/camera or collect sensitive counselling information until the service has clinical governance, privacy review, secure authentication and safeguarding controls. The current web prototype is not a live clinical service.
